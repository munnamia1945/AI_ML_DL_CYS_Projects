# AI/ML Projects Portfolio

A structured portfolio of 32 AI/ML, deep learning, cybersecurity, and research projects.

## Project structure
Each numbered project has its own folder. Add the Google Colab/Jupyter notebook, project README, results, and any requirements file inside the corresponding folder.

## Suggested files per project
- `project-notebook.ipynb` — notebook exported from Google Colab
- `README.md` — objective, dataset/source, methods, evaluation, results, limitations
- `results/` — plots and evaluation outputs, if useful
- `requirements.txt` — dependencies, when needed

## Important
- Do not claim results until you have run the experiment.
- Cite dataset sources and check their licenses.
- Avoid committing API keys, passwords, private data, or large datasets.
